- 대상: `Content/QuakeLike_1_0/GameFlow/UI/WBP_MapSelect_SDM` (이 에셋만 수정)
- 색 출처: `02_Styles/03_Palette/PDA_UIPalette` (읽기만. **팔레트 값은 바꾸지 않는다**)
- 앞선 지시서(`CODEX_지시서_싱글플레이_선택화면.md`)의 원칙(재활용, 삭제·이름 변경 금지, 보고 형식)을 그대로 따른다.

## 0. 먼저 확인할 것 (수정 전에 보고)

2026-11-14에 팔레트 에셋의 바이너리에서 읽은 값이다. 에디터에서 실제 값과 일치하는지 먼저 확인하고, 다르면 멈추고 보고한다.

| 토큰 | 읽은 값 |
|---|---|
| `Accent` | `FFE568` |
| `White` / `Text1` | `F4F6FA` |
| `Text2` | `F4F6FA` 70% |
| `DiffEasy` | `34D399` (초록) |
| `DiffNormal` | `FFE568` (노랑, `Accent`와 같은 값) |
| `DiffHard` | `FF4D5A` (빨강) |
| `DiffNormalGlowBlue` | `42B9E3` (파랑) |

또한 `WBP_MapSelect_SDM`의 색이 **팔레트를 참조하는지, 같은 값을 직접 입력한 것인지** 확인해 보고한다. (바이너리에는 `UIThemePaletteLibrary` 호출이 보이지 않고 색 값이 직접 들어 있다. 팔레트가 위젯 속성에 값을 밀어 넣는 방식이라면 정상이다.) 직접 입력한 색이 있으면 이 프로젝트의 기존 방식대로 팔레트에 연결한다.

## 1. '보통' 난이도 색을 파랑으로

- 문제: `DiffNormal`이 `Accent`와 같은 노랑이라, 기본 선택(보통)과 시작 버튼이 같은 색으로 보인다.
- 수정: 이 화면의 '보통' 버튼에서 **눈금 색과 선택 시 이름 색**을 `DiffNormalGlowBlue`로 바꾼다.
- 쉬움(`DiffEasy`)과 어려움(`DiffHard`)은 그대로 둔다.
- `RefreshDifficultyStyle`에서 난이도별 색을 고르는 곳도 같은 토큰을 쓰도록 맞춘다.
- 새 색·새 토큰을 만들지 않는다. 팔레트의 `DiffNormal` 값 자체는 다른 화면에 영향을 주므로 건드리지 않는다.

## 2. 선택 표시는 흰색, 노랑은 실행과 포커스에만

- 문제: 선택된 맵 카드의 테두리·꺾쇠와 선택된 난이도의 꺾쇠가 노랑(`FFCD26` 근처)이다. 노랑이 '선택'과 '실행' 두 뜻을 갖고, 키보드 포커스 표시와 구분되지 않는다.
- 수정:
  - 선택된 맵 카드의 테두리와 네 모서리 꺾쇠 → `White`
  - 선택된 난이도 버튼의 꺾쇠 → `White`
  - 선택 안 된 맵 카드의 얇은 회색 구분선은 그대로 둔다.
- 이 화면에서 `Accent`를 쓰는 곳은 **시작 버튼 바탕**과 **키보드·패드 포커스 테두리**뿐이어야 한다.
- 참고: 지금 선택 테두리 색은 `FFCD26` 근처로, 위 표의 어느 토큰과도 일치하지 않는다. 어디서 온 색인지(머티리얼 인스턴스, 버튼 스타일, 직접 입력) 찾아서 보고한다.

## 3. 하지 않는 것

- 팔레트 값 변경, 새 토큰·새 머티리얼·새 스타일 추가
- 배치·크기·간격·문구·동작 변경
- `WBP_MapSelect_SDM` 외 에셋 수정 (꼭 필요하면 먼저 보고)

## 4. 완료 기준

1. 쉬움 초록, 보통 파랑, 어려움 빨강으로 표시된다.
2. 화면을 열었을 때 노랑은 시작 버튼에만 보인다(마우스로만 조작할 때).
3. 선택된 맵·난이도의 꺾쇠가 흰색이다.
4. 키보드·패드 포커스 테두리는 노랑이며, 선택 꺾쇠(흰색)와 동시에 보여도 구분된다.
5. 컴파일 오류·경고 0건. 변경 전후 스크린샷(1920×1080)을 첨부한다.
6. 0장의 확인 결과와 2장의 `FFCD26` 출처를 보고에 포함한다.
