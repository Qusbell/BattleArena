# 로컬 에임 어시스트

2026-11-10 grilling 인터뷰에서 명세와 문서 작성 후 구현을 승인받았습니다.

## 결정

- Shipping 포함, 기본 OFF입니다. Ctrl+Shift+Alt를 누르고 F10을 새로 누르면 토글하며 ON/OFF를 짧게 표시합니다. 로컬 플레이어에게만 적용합니다.
- ON 상태에서 좌클릭을 누르는 동안 작동합니다. 탄약·실제 발사 가능 여부와 무관하며 모든 사격 무기에 적용합니다.
- 살아 있는 적 플레이어·AI 중 가슴이 화면 안에 있고 가려지지 않은 대상을 선택합니다. 가슴의 화면 좌표와 조준점 사이 거리가 가장 작은 적을 매 프레임 다시 선택합니다. 거리·각도 제한과 대상 고정은 없습니다.
- 현재 가슴 위치를 향해 카메라와 사격 방향을 함께 보간합니다. 선행 조준은 없습니다. 프레임률에 무관한 지수 감쇠로 고정 대상에 대한 초기 각도 차이의 90%를 약 0.3초에 줄이며 속도를 설정할 수 있습니다.
- 유효한 대상을 추적하는 동안 마우스 시점 입력을 차단합니다. 대상이 없거나 좌클릭을 놓으면 즉시 허용합니다.
- 메뉴·일시정지·사망·관전·포커스 상실 중에는 중지합니다. 정상 플레이 복귀 후 현재 좌클릭 상태에 따라 재개합니다. 별도 입력 차단 상태를 누적하지 않습니다.
- 토글 상태는 로컬 PlayerController 수명 동안 유지하고 새 컨트롤러에서는 OFF로 초기화합니다. 별도 저장 및 맵 간 전달은 하지 않습니다. 중단·재개와 상태 수명은 사용자가 구현 재량을 위임했고 최종 명세에서 확인한 내용입니다.

## 구현 경계

기존 BP_PlayerShooter.GetAim은 GetBaseAimRotation을 사용합니다. 컨트롤러 회전을 보간하여 기존 발사·복제·탄도 경로를 유지합니다. 가슴은 기존 GetHeart, 생존은 기존 LifeInfo와 CharacterPool을 사용합니다. 사용자의 후속 확인에 따라 PlayerState.Team은 사용하지 않으며 자신 이외의 모든 Pawn을 적으로 간주합니다. PlayerState가 없어도 후보가 될 수 있고, 관전자 Pawn/관전자 상태·사망·숨김·가슴 정보 부재·화면 밖·엄폐는 제외합니다.

## 검증 계획

수렴 시간·프레임률·각도 경계, 후보의 화면 위치·엄폐·생존·관전·재선택, PlayerState 부재, 입력 해제와 토글, 기존 GetAim 연결 및 Editor/Shipping 컴파일을 확인합니다. Git 소스 빌드 엔진이 필요한 서버/Cook/패키징 실행과 실제 수행한 검증은 시스템 문서에서 구분합니다.
