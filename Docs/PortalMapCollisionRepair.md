# Lvl_PortalMap 충돌 후처리

대상: `/Game/QuakeLike_Base/Lvl_PortalMap`, NavMeshBoundsVolume 내부 플레이 공간.

## 적용 내용

- 벽·기둥·통로 메시 106개 인스턴스의 누락된 면에 숨김 박스 충돌 2,560개를 보충했다. 원본별 ISM 액터 106개로 묶었으며, 원본 메시 에셋은 수정하지 않았다.
- 계단 메시 11개를 9개 연속 동선으로 묶고 기존 단별 충돌을 해제했다. 디딤면 상단과 계단참을 잇는 경사 슬래브 26개를 9개 ISM 액터에 배치했다. 두께는 12cm이며 계단 아래 공간을 채우지 않는다.
- `Loigh02_Clean342`, `Loigh02_Clean343`, `SM_Ramp3`의 충돌을 해제했다. 각각 통행 방해를 확인하고 아래 지지면을 별도로 확인했다. `SM_Ramp3`는 주 경사로가 아니라 기둥 옆 바닥 위에 겹친 작은 모서리 마감재다.
- 앞서 적용한 점프패드 4곳의 메시·덮개 `NoCollision`을 유지했다. 점프 발동 트리거는 유지한다.
- Navigation을 다시 생성했다. 캐릭터 크기, 이동 설정, Nav Agent 설정, 원본 메시·블루프린트·전역 충돌 프리셋은 수정하지 않았다.

보충 액터는 아웃라이너의 `CollisionFix/Wall`, `CollisionFix/Stair` 폴더에 있으며 `PortalCollisionFix`, `PCFId=…`, `PCFSource=…` 태그로 식별한다. 동일한 계획을 다시 적용하면 기존 ISM을 갱신하므로 중복 액터를 만들지 않는다. World Partition의 External Actor 패키지와 폴더 External Object 패키지에 저장했다.

## 검증

- 보충 벽 2,560면 모두 원본 삼각형 표면 및 Pawn·Projectile·RailGun 채널 검사 통과.
- 원래 관통하던 벽의 39개 레이 표본과 5개 캡슐 표본 차단 확인.
- 경사 슬래브 26개 모두 의도한 표면 높이·기울기로 실제 충돌 생성 확인.
- SIE의 실제 `BP_AIShooter`로 계단 왕복 18회, 조명 구간 왕복 4회, 점프패드 발동 4회 통과.
- 추가 경사로·모서리 후보 8곳 왕복 16회 통과. 최초 `SM_Ramp3` 역방향 검사에서 생긴 옆밀림을 수정한 뒤 양방향 재검사했다. 나머지 후보는 정상 통행이 확인되어 기존 충돌을 유지했다.
- 최종 이동·발동 검사 42/42 통과. AI 런타임 캡슐은 반경 51cm·반높이 132cm였으며 검증 속도는 800cm/s였다. BT와 PathFollowing의 자율 입력을 SIE 안에서만 중지하여 이동 입력을 분리했다.
- 저장 후 원본 메시·충돌 설정, 보충 인스턴스 2,586개의 위치·회전·크기, 점프패드 트리거를 새 패키지 로드로 재검증했다. 계단 동선 9곳의 Navigation 경로도 확인했다.

## 조사·검증 도구와 기록

- `Tools/LevelCollision/portal_map_collision.py`: 대상 레벨의 면 검사, 경사면 생성, 인스턴스 수정, 선택 저장. `audit_*`는 계획만 작성하고, `apply_surfaces()`·`apply_walls()`·`save()`는 명시적으로 호출해야 한다.
- `Tools/LevelCollision/portal_map_collision_validate.py`: SIE 월드의 실제 AI로 이동·점프패드 검증. 에디터 월드나 게임플레이 블루프린트는 수정하지 않는다. 검증 후 SIE를 종료하여 임시 AI 제어 변경을 폐기한다.
- `Saved/CollisionAudit/Lvl_PortalMap/repair_report.json`: 액터 경로·원래 충돌 설정·보충 형상·채널 검사·시뮬레이션 이동 궤적 및 저장 패키지 목록. 로컬 상세 기록이며 Git에는 포함하지 않는다.

개별 예비 후보의 형상 차이만으로 충돌을 끄지 않았다. 원래 구조물에 막히는 경우와 단차로 정상 통과하는 경우는 수정 대상에서 제외했다.

Python에서 재로딩을 검증할 때는 이전 World·Actor·Component 참조를 해제하고 대상 외부 패키지를 언로드한 뒤 다시 로드해야 한다. 이전 참조를 유지한 채 같은 레벨만 다시 열면 캐시된 네이티브 컴포넌트가 기본값으로 보일 수 있다. 이번 검증에서는 빈 임시 맵으로 전환하고 참조·패키지를 모두 해제한 뒤 저장 파일을 새로 읽었다.
