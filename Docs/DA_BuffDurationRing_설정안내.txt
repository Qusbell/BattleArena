DA_BuffDurationRing 조절 안내
작성 기준일 2026-11-12

대상 에셋
/Game/QuakeLike_1_0/Data/UI/DA_BuffDurationRing
콘텐츠 브라우저에서 위 에셋을 열고 Details에서 조절한 뒤 저장합니다.
아래 범위와 예시는 현재 코드 기준입니다. 현재 DA에 저장된 값의 목록은 아닙니다.
이 DA는 버프 HUD의 표현을 조절합니다. 버프의 실제 지속시간·공격력·방어력은 별도 게임플레이 데이터에서 조절합니다.

먼저 구분할 세 가지
1) 지속시간 링 — 남은 시간에 따라 줄어드는 바깥 게이지
2) 링 윤곽선 — 지속시간 링의 안쪽과 바깥쪽을 따라 보이는 선
3) 아이콘 원형 테두리 — 아이콘을 감싸는 별도 고정 프레임

자주 하는 조절
- 흰색 선이 두꺼우면 → 원형 게이지 > 흰색 윤곽선 두께 (px)를 낮춥니다.
- 흰색 선 색을 바꾸려면 → 원형 게이지 > 윤곽선 색상을 바꿉니다.
- 게이지 자체가 두꺼우면 → 원형 게이지 > 링 두께를 1에 가깝게 낮춥니다.
- 감소하는 끝이 너무 밝으면 → 원형 게이지 > 끝부분 발광의 밝기를 낮춥니다.
- 링 주변 빛이 너무 퍼지면 → 링 발광 > 발광 퍼지는 범위를 낮춥니다.
- 광택이 닿는 원을 넓히려면 → 흰색 반짝임 > 원형 영역 반짝임 범위 배율을 올립니다.
- 움직이는 광택을 전부 끄려면 → 흰색 반짝임의 세 체크박스를 모두 해제합니다.
  기존 밝기 펄스도 끄려면 아이콘 반짝임 > 반짝임 사용도 해제합니다.

1. 위치·크기
- 위치 (하단 중앙 기준)
  버프 UI 전체 위치입니다. X는 좌우, Y는 상하입니다. 음수 Y는 위쪽으로 이동합니다.
- 원형 게이지 지름
  지속시간 링의 지름입니다. 범위 16~1024입니다.
  아이콘 크기와 아이콘 원형 프레임 지름은 각각 별도 항목입니다.
  UI 크기는 화면 해상도와 DPI 배율의 영향을 받습니다.

2. 원형 게이지
- 링 표시
  지속시간 링을 표시합니다.
- 게이지 형태
  연결형은 하나로 이어진 고리, 분할형은 마디 사이에 간격이 있는 고리입니다.
  링 패턴 반복 수는 분할형에서 마디 수를 지정합니다. 5이면 5개 마디입니다.
- 링 두께 (1에 가까울수록 얇음)
  게이지 띠 전체 두께입니다. 범위 1.001~2입니다.
  현재 연결형 머티리얼에는 가독성을 위한 최소 두께가 있어, 아주 얇게 낮추면 변화가 제한됩니다.
- 흰색 윤곽선 두께 (px)
  링 안쪽·바깥쪽 선의 두께입니다. 색상을 바꾸더라도 항목명은 '흰색'으로 표시됩니다.
  범위 0~4입니다. 0은 윤곽선 없음, 0.5는 얇게, 0.75는 기본 기준, 1 이상은 더 두껍게 표현합니다.
  채움을 확보하도록 실제 윤곽 두께는 게이지 두께에 따라 제한됩니다.
- 윤곽선 색상
  링 안팎 윤곽선의 RGB 색상입니다. 두께와 독립적으로 조절합니다.
  분할 윤곽선 그라데이션을 켜면 마디 양 끝의 밝은 색상으로 사용합니다.
- 원형 게이지 > 윤곽선 > 윤곽선 불투명도
  0은 완전 투명, 1은 불투명입니다. 남은 마디와 소진된 마디의 윤곽선에 함께 적용합니다.
- 분할 윤곽선 그라데이션 사용
  분할형에서 마디 중앙은 어둡고 양 끝은 밝게 이어지게 합니다.
- 마디 중앙 윤곽선 색상
  각 마디 가운데의 어두운 색상입니다.
- 마디 끝 밝기 퍼짐 범위
  0.01~0.5입니다. 높이면 양 끝의 밝은 부분이 중앙으로 더 넓게 퍼집니다.
- 시작 각도 (-90 = 12시)
  게이지 감소의 시작 위치입니다. -90은 위쪽, 0은 오른쪽입니다.
- 쿼드 색상 / 프로텍션 색상
  링 그라데이션을 껐을 때 버프 종류별 채움 색상입니다.
- 소진된 구간 색상·불투명도
  소진된 구간의 트랙 색상입니다. 현재 연결형 머티리얼은 RGB를 어두운 바탕과 혼합합니다.
  현재 구현에서는 이 항목의 알파로 트랙을 투명하게 만들 수 없습니다.
- 소진된 구간 배경 투명하게
  체크하면 감소 후 남는 어두운 트랙 배경을 투명하게 표시합니다.
  안팎 윤곽선과 남은 게이지 채움은 유지합니다. 해제하면 기존 어두운 트랙을 표시합니다.
- 링 패턴 반복 수
  분할형에서 마디 수를 조절합니다. 연결형에서는 적용되지 않습니다.
  정수로 입력합니다. 너무 큰 값은 마디 간격을 식별하기 어려우므로 5~12부터 조절합니다.

3. 링 그라데이션
- 링 그라데이션 사용
  켜면 시작·끝 색상으로 채움을 표현하고, 끄면 쿼드·프로텍션 색상을 사용합니다.
- 시작 색상 / 끝 색상
  링 둘레의 두 색상입니다. 기준점에서 시작 색상, 반대쪽에서 끝 색상으로 바뀐 뒤 다시 시작 색상으로 이어집니다.
  끝 색상은 남은 시간의 끝부분 색상을 뜻하지 않습니다.
- 기준 각도 (°)
  그라데이션 배치 방향입니다. 0은 12시 기준이며 양수는 시계 방향입니다. 적용 범위 -360~360입니다.
  현재 연결형 링의 안쪽 명암 강도는 머티리얼에 고정되어 있으며 DA 전용 항목은 없습니다.

4. 원형 게이지 > 끝부분 발광
- 게이지 끝부분 발광 사용
  감소하는 게이지 끝의 강조를 켭니다.
  끄더라도 연결형 링과 끝의 짧은 경계는 남습니다.
  에디터 툴팁의 '기존 5분할 링' 문구는 이전 설명이며 현재 연결형 동작과 다릅니다.
- 끝부분 발광 밝기
  범위 0~1입니다. 높이면 채움 끝이 더 밝아집니다.
- 끝부분 발광 폭 (px)
  범위 1~32입니다. 높이면 끝에서 채워진 호 뒤쪽으로 밝은 부분이 더 길게 이어집니다.
  링 전체 주변으로 퍼지는 빛은 다음 '링 발광' 항목에서 조절합니다.

5. 링 발광
- 링 발광 사용
  채워진 링 바깥쪽으로 퍼지는 빛을 켭니다.
- 발광 강도
  적용 범위 0~1입니다. 0이면 주변 빛이 사라집니다.
- 발광 퍼지는 범위
  적용 범위 1~48입니다. 높이면 빛이 더 멀리 퍼집니다.
- 사용자 지정 발광 색상 사용
  끄면 링의 위치별 색상을 따릅니다. 켜면 아래 발광 색상을 사용합니다.
- 발광 색상
  사용자 지정 색상을 켰을 때의 주변 빛 RGB 색상입니다.
  링 본체의 색상은 링 그라데이션 또는 쿼드·프로텍션 색상으로 조절합니다.

6. 가운데 아이콘
- 아이콘 표시 / 아이콘 텍스처
  아이콘 표시와 그림을 지정합니다.
- 아이콘 색상
  아이콘 tint입니다. 색상의 알파와 아래 불투명도 값은 곱해집니다.
- 아이콘 크기
  X는 가로, Y는 세로 크기입니다. 아이콘 프레임과 링 크기는 별도입니다.
- 아이콘 위치 (중앙 기준)
  아이콘의 위치입니다. 원형 프레임과 원형 광택도 이 중심을 따라갑니다.
- 아이콘 불투명도 (0=투명, 1=불투명)
  아이콘 그림의 불투명도입니다.
- 아이콘 블러 강도 (0=선명)
  범위 0~12입니다. 높이면 아이콘이 부드럽게 흐려집니다.

7. 아이콘 원형 테두리
- 원형 테두리 표시
  아이콘을 감싸는 고정 프레임을 켭니다.
- 테두리 색상
  고정 프레임의 색상과 알파입니다.
- 테두리 선 두께
  프레임 선 두께입니다. 최소 0.1, 최대 프레임 지름의 절반까지 적용됩니다.
- 원형 테두리 지름
  적용 범위 1~1024입니다. 아이콘과 중심을 공유합니다.
  프레임 표시를 꺼도 이 지름은 원형 영역 반짝임 범위의 기준으로 사용됩니다.

아이콘 배경
- 아이콘 배경 표시
  아이콘 뒤의 원형 배경을 켭니다. 블러는 적용하지 않습니다.
- 배경 색상 / 배경 불투명도 (0=투명, 1=불투명)
  배경 RGB와 불투명도를 독립 조절합니다.
  중심은 아이콘 위치를 따릅니다.
- 배경 지름
  원형 테두리와 독립적인 배경 원의 지름입니다. 범위 1~1024입니다.
- 배경 그라데이션 사용
  중앙에서 바깥 색상으로 이어지는 원형 그라데이션을 켭니다.
  기존 배경 색상이 중앙 색상입니다.
- 배경 바깥 색상
  원 가장자리와 번지는 영역의 RGB 색상입니다.
- 배경 중간 색상
  중앙 색상과 바깥 색상 사이를 이어주는 색상입니다.
  가장자리로 사라지는 효과는 배경 바깥 불투명도를 0으로 설정합니다.
- 배경 중간 색상 위치 (%)
  배경 반지름 기준 중간 색상의 위치입니다. 28이면 중심에서 반지름의 28% 지점입니다.
  범위 1~99입니다. 작게 하면 중심 쪽, 크게 하면 가장자리 쪽으로 이동합니다.
  중앙 색상 유지 비율보다 안쪽으로 옮기면 실제 유지 구간도 중간 지점 안쪽으로 제한됩니다.
  바깥 색상의 불투명도 및 번짐 범위와 독립적으로 색상 중지점의 위치를 조절합니다.
- 배경 바깥 불투명도 (0=투명, 1=불투명)
  가장자리와 번짐 영역의 불투명도를 중앙과 독립 조절합니다.
  기존 배경 불투명도는 중앙에 적용하며 두 값은 그라데이션 구간에서 보간됩니다.
  배경 그라데이션을 꺼두면 기존 배경 불투명도만 적용합니다.
- 중앙 색상 유지 비율
  0~0.95입니다. 높이면 중앙 색상이 더 넓게 유지됩니다.
- 바깥 번짐 범위
  0~128 UI 단위입니다. 배경 반지름 밖으로 바깥 색이 투명해지는 거리입니다.
  그라데이션을 끄면 단색 원으로 표시됩니다.

8. 아이콘 반짝임 — 기존 밝기 펄스
- 반짝임 사용
  아이콘의 밝기가 짧게 올라오는 기존 효과입니다.
- 반짝임 강도
  범위 0~4입니다. 0이면 밝기 강조가 없습니다.
- 반짝임 간격 (초)
  범위 0.05~60입니다. 작을수록 자주 재생됩니다.
  이 값은 아래 흰색 광택의 재생 간격에도 사용되므로 함께 확인합니다.
- 반짝임 지속시간 (초)
  범위 0.01~2입니다. 실제 적용 길이는 반짝임 간격을 넘지 않습니다.
  기존 밝기 펄스의 길이이며 흰색 광택의 이동 시간은 바뀌지 않습니다.

9. 흰색 반짝임 — 이동하는 흰색 광택
- 아이콘 흰색 반짝임 사용
  아이콘 그림의 불투명한 부분을 따라 광택이 지나갑니다.
- 원형 테두리 흰색 반짝임 사용
  이름의 '테두리'는 현재 지속시간 링의 광택을 뜻합니다.
  별도 고정 프레임만 반짝이게 하는 체크박스는 아닙니다.
- 원형 영역 반짝임 사용
  아이콘 주변의 원형 영역 전체에 광택 띠가 지나갑니다. 고정 프레임까지 함께 덮을 때 사용합니다.
- 원형 영역 반짝임 범위 배율
  광택 원 지름 = 원형 테두리 지름 × 배율입니다. 적용 범위 0.1~3입니다.
  0.8은 프레임보다 20% 작은 지름, 1.0은 같은 지름, 1.2는 20% 큰 지름입니다.
  아이콘 크기·프레임 크기를 바꾸는 값이 아닙니다.
- 공통 동작
  활성화된 광택은 같은 재생 시점을 공유합니다. 현재 한 번 이동하는 시간은 코드에서 0.32초로 고정되어 있습니다.
  버프 최초 표시와 반짝임 간격 경계를 지날 때 재생하며, 재생 중 중복 시작은 건너뜁니다.
  아이콘 광택과 원형 영역 광택을 함께 켜면 겹친 마스크 중 큰 값을 사용합니다.
  아이콘 표시를 끄면 아이콘·고정 프레임·원형 영역 광택도 숨겨집니다.
  숫자는 이 광택 레이어 위에 그려집니다.

10. 가운데 숫자 / 숫자 종료 경고
- 남은 시간 표시
  남은 시간 숫자 표시 여부입니다.
- 숫자 글자 크기
  범위 8~128입니다.
- 숫자 위치 (중앙 기준)
  숫자만 이동합니다.
- 숫자 색상 / 숫자 외곽선 두께
  기본 숫자 색과 윤곽 두께입니다. 외곽선 범위 0~8입니다.
- 초 단위 s 표시
  켜면 45s처럼 표시합니다. 끄면 숫자만 표시합니다.
- 남은 시간 숫자 깜빡임 사용
  만료가 가까울 때 숫자 색상을 바꾸는 경고입니다.
- 경고 시작 잔여시간 (초)
  범위 0.1~60입니다. 예를 들어 5이면 5초 이하부터 경고합니다.
- 숫자 경고 색상
  기본 숫자 색상과 번갈아 표시할 색상입니다.
- 숫자 깜빡임 주기 (초)
  범위 0.05~10입니다. 한 주기의 절반은 경고 색, 나머지는 기본 색입니다.

11. 기본 자막
- 기본 대사 자막 표시
  게임의 기본 사운드 자막 표시 여부입니다. 버프 UI 외 기본 대사 자막에도 적용됩니다.
- 자막 위치 비율 (X=좌우, Y=높이)
  화면 좌상단 0,0 / 우하단 1,1입니다. X=0.5는 중앙입니다.
- 자막 글자 크기 배율
  범위 0.25~4입니다. 1은 기존 크기, 1.5는 150%입니다.

Icon White Shine Material, Icon Frame Material은 효과 구현용 참조입니다.
일반 디자인 조정은 위 체크박스·색상·수치로 진행합니다.

조정 후 확인
1) DA를 저장하고 실제 버프를 획득해 확인합니다.
2) 먼저 링 발광과 끝부분 발광을 끈 채 윤곽·채움·끝 경계를 확인합니다.
3) 두 발광을 하나씩 켜 밝고 어두운 배경에서 확인합니다.
4) 반짝임 범위는 0.8 / 1.0 / 1.2를 비교합니다.
5) 버프 만료와 재획득 시 이전 효과가 남지 않는지 확인합니다.
