# 드롭 아이템 획득 판정

`BP_DropItem`의 `PickupContactComponent`는 서버에서 획득 구체를 활성화하고, Blueprint 초기화가 끝난 뒤 기존 BeginOverlap 획득 경로로 접촉을 전달한다. 준비 전 접촉은 최대 0.1초 동안 유지하며, 준비 이후에도 겹쳐 있는 대상은 시간 경과와 관계없이 시도한다. 이동하는 아이템의 이전 위치와 현재 위치 사이에는 Pawn 대상 구체 Sweep을 수행한다. 기존 Blueprint의 효과 적용·중복 획득 잠금과 버프 수명 처리는 유지한다.

`Project Settings > Game > Item Pickup > Radius`는 새로 생성되는 맵 아이템과 사망 드롭의 월드 기준 반경(cm)이다. 기본값은 135 cm이며, 이전 부모 Blueprint의 70 cm 반경과 1.5 스케일에 해당하는 105 cm에서 늘렸다. 설정 변경은 새 아이템부터 적용한다. 메시의 크기를 바꾸지 않는다.

2026-11-10 일반 Editor 빌드 성공. 서버 PIE의 격리된 AI 폰 위치에 버프 아이템을 생성한 시험에서 반경 135 cm와 생성 후 해당 폰의 버프 획득을 확인했다. 고속·점프 상황, 예약 만료 및 경쟁 조건, 다른 아이템과 패키징 빌드는 검증하지 않았다. 상세 결정과 작업 이력은 [결정 문서](../../../Decision/001-drop-item-pickup.md)를 참조한다.
