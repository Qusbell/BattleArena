# 버프 로직 안정화 및 종료 예고음

## 업무 정보

- 형태: 기존 버프 로직 안정화 + 신규 종료 예고음 구현
- 담당자: 이준혁
- 직군: 프로그래밍
- 파트: BUFF / DT / VFX / SOUND / TIMER
- 우선순위: 높음
- 마감: 미지정

## 요청 범위와 배경

기존 Quad Damage와 Protection 기능 및 기획 규칙을 유지한다. 버프 획득 순간 일시적인 렉이 관찰됐고 처리 구조의 안정성 우려도 제기됐으나, 원인은 미확정이다. 먼저 재현과 측정을 진행하고, 확인된 내부 처리 문제만 수정·최적화한다. 이번 작업은 버프 리뉴얼이 아니다.

획득 시 호출 흐름, DataTable 리소스 로딩, VFX/Sound 생성, 중복 이벤트, 서버/클라이언트 처리, 공유 타이머를 점검한다. Niagara와 Cascade 개별 지정 및 동시 적용, 획득음, 남은 시간 표시를 유지하고 연동을 확인한다.

다음 동작은 기능적으로 변경하지 않는다: Quad Damage 및 Protection 효과, 로켓 자해 관련 처리, 버프 교대 스폰, 획득 여부 판정, 공유 지속시간, 종료 처리와 VFX 정리. 구조 변경이 불가피하면 변경 범위·영향·위험을 먼저 공유한다.

## 확정된 종료 예고음 규칙

- 기존 공유 버프 타이머의 Remaining Time을 단일 기준으로 사용한다. 서버 기준은 `EndServerTime`이다.
- 남은 5, 4, 3, 2, 1초 구간에 같은 예고음을 각각 한 번씩 재생한다. 0초에는 별도 종료음을 추가 재생하지 않는다.
- 획득음과 종료 예고음은 리소스, 발생원, 출력 설정을 분리한다. 버프별 사운드와 볼륨 배율을 Buff DT에서 지정한다. 각 볼륨 기본값은 1.0이며 0은 무음이다.
- 획득음의 World 모드는 버프 획득 순간의 월드 좌표를 중심으로 퍼지게 한다(A/B 테스트 대상).
- Buff DT에 `bWarningLocalEnabled`, `bWarningWorldEnabled` 체크박스를 각각 둔다. 두 설정은 독립적이며 Local Only, World Only, Both, None을 허용한다.
- Local 종료 예고음은 현재 버프 보유자에게만 2D로 출력한다.
- World 종료 예고음은 현재 보유자 캐릭터의 Scene Component에 붙여 3D로 출력한다. 보유자 이동을 따라가며 주변 인원은 감쇠된 소리로 듣는다. 획득 위치에 고정하지 않는다.
- Local/World 종료 예고음의 볼륨을 각각 조절한다. World Attenuation도 기획자가 조절할 수 있게 한다.
- Both는 의도된 2D와 3D 동시 출력이다. 각 경로에서 같은 음이 중복 호출되는 오류는 막는다.
- 사망, 드롭, 재획득 시 CurrentOwner 참조와 오디오 핸들을 갱신한다.
- PIE 및 패키징 테스트 빌드에서 Local Only / World Only / Both / None을 즉시 전환할 수 있는 테스트 제어를 제공한다.

## 첨부 체크리스트 — [1순위] 필수 개발 · 로직 안정화

- [ ] 버프 획득 순간 렉을 재현하고 Unreal Insights/프레임 타임 등으로 실제 발생 지점을 확인
- [ ] 획득 이벤트 호출 흐름, 중복 실행·반복 처리, 불필요한 객체 생성 여부 점검
- [ ] Buff DT 참조 및 Niagara/Particle/Sound 리소스 동기 로딩·초기화 비용 확인
- [ ] 서버·클라이언트 중복 처리, 버프 상태 전환 및 공유 타이머 갱신 로직 점검
- [ ] 원인 확인 후 문제 있는 로직 중심으로 수정·최적화 (기능 동작은 유지)
- [ ] Buff DT에 획득음 및 종료 예고음 리소스를 버프별 지정하도록 구현
- [ ] Buff DT에서 획득음/종료 예고음 볼륨 배율을 각각 설정 (기본 1.0, 0은 무음)
- [ ] 기존 공유 Remaining Time 기준 5·4·3·2·1초 시점에 동일 예고음을 각 1회, 총 5회 재생
- [ ] 별도의 독립 카운트다운 없이 시간 동기화·중복 출력 방지, 0초 추가 재생 방지
- [ ] Niagara + Particle 개별 DT 설정·동시 적용/종료 정리 및 획득음 1회 재생 유지
- [ ] Quad Damage/Protection 공통 로직을 사용하고 DT 설정값으로 VFX/Sound 구분
- [ ] Buff DT에 종료 예고음 Local/World 독립 Bool 체크박스 2개 추가 (둘 다 ON 허용)
- [ ] 종료 예고음 World를 현재 버프 보유자 Scene Component 기준 Spawn Sound Attached로 출력, 획득 위치 고정과 분리
- [ ] Local/World 종료 예고음의 볼륨 및 World Attenuation 설정을 개별 조절 가능하게 구현
