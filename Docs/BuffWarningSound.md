# 버프 사운드 사용법

## 1. 설정할 DT 열기

콘텐츠 브라우저에서 `DT_BuffTable`을 검색해서 연다.

폴더: `QuakeLike_1_0 → Data → Item → DropTable`

왼쪽 목록에서 수정할 버프 행을 선택한다. 행마다 사운드를 다르게 설정할 수 있다.

## 2. 종료 예고음 설정하기

버프 종료가 가까워졌을 때 울리는 소리는 아래 항목으로 설정한다.

| 항목 | 설정 방법 |
| --- | --- |
| `WarningSound` | 원하는 Sound Cue 또는 Sound Wave를 넣는다. |
| `WarningLocalEnabled` | 체크하면 버프를 가진 사람에게만 2D로 들린다. |
| `WarningWorldEnabled` | 체크하면 버프를 가진 사람을 따라가는 3D 소리가 나고, 주변 사람도 듣는다. |
| `WarningLocalVolume` | 2D 소리 크기. 우선 `1.0`으로 둔다. |
| `WarningWorldVolume` | 3D 소리 크기. 우선 `1.0`으로 둔다. |
| `WarningAttenuation` | 3D 소리가 얼마나 멀리 들리는지 정하는 에셋. 비워 두면 기본 거리 설정을 사용한다. |

체크박스 두 개는 이렇게 조합한다.

| 원하는 방식 | Local 체크 | World 체크 |
| --- | --- | --- |
| 버프를 가진 사람에게만 들리기 | 켬 | 끔 |
| 주변에도 3D로 들리기 | 끔 | 켬 |
| 2D와 3D 둘 다 사용하기 | 켬 | 켬 |
| 예고음 끄기 | 끔 | 끔 |

둘 다 켜면 보유자는 2D와 3D를 함께 듣는다. 너무 크면 두 볼륨을 낮춰 조절한다.
볼륨 `0`은 해당 소리만 끈다. `WarningSound=None`이면 예고음이 나오지 않는다.

## 3. 게임에서 확인하기

1. DT를 저장한다.
2. 게임을 실행하고 수정한 버프를 획득한다.
3. 남은 시간이 5·4·3·2·1초일 때 같은 예고음이 한 번씩 나오는지 확인한다.

BP에 예고음 노드를 추가할 필요는 없다.
DT를 수정한 뒤에는 버프를 새로 획득하거나 갱신해서 확인한다.

현재는 네 행 모두 임시 사운드 `hit_Pitch_Changer__1_`, Local 켬 / World 끔 / 두 볼륨 `1.0`으로 설정되어 있다.
최종 사운드가 정해지면 `WarningSound`만 교체하면 된다.

## 4. 실행 중 출력 방식 비교하기

게임 콘솔 또는 에디터 Output Log 아래의 명령 입력칸에 입력한다.

| 명령 | 출력 방식 |
| --- | --- |
| `Buff.WarningSound.Mode 1` | 보유자만 2D |
| `Buff.WarningSound.Mode 2` | 주변에도 3D |
| `Buff.WarningSound.Mode 3` | 2D + 3D |
| `Buff.WarningSound.Mode 0` | 예고음 끄기 |
| `Buff.WarningSound.Mode -1` | DT 체크박스 설정으로 돌아가기 |

**비교가 끝나면 반드시 `Buff.WarningSound.Mode -1`로 돌린다.**
`0~3`에서는 DT 체크박스를 바꿔도 출력 방식이 바뀌지 않는다.
사운드와 볼륨은 계속 DT 값을 사용하므로, Sound가 비어 있거나 볼륨이 0이면 들리지 않는다.

모드는 다음 예고 시점부터 바뀐다. 이미 지나간 예고음은 다시 재생하지 않는다.
멀티플레이를 별도 프로그램으로 실행했다면 각 클라이언트 콘솔에서 명령을 입력한다.

## 5. 획득음 바꾸기

버프를 먹는 순간의 소리는 같은 DT의 아래 항목을 수정한다.

- `PickupSound`: 획득할 때 낼 소리.
- `PickupVolume`: 획득음 크기. `1.0`은 원래 음량, `0`은 무음.

획득음의 출력 방식은 별도 명령으로 비교한다.

| 명령 | 출력 방식 |
| --- | --- |
| `Buff.PickupSound.Mode 0` | 획득한 사람에게만 2D (현재 기본값) |
| `Buff.PickupSound.Mode 1` | 버프를 획득한 위치에서 3D |

획득음의 3D는 획득한 위치에 남고, 종료 예고음의 3D는 보유자를 따라간다.

## 소리가 안 들리면

1. `WarningSound`에 사운드가 들어 있는지 확인한다.
2. 사용할 경로의 볼륨이 `0`이 아닌지 확인한다.
3. `Buff.WarningSound.Mode -1`을 입력하고 Local 또는 World를 켠다.
4. DT를 저장하고 버프를 다시 획득해 남은 5초까지 기다린다.

재생 로그가 필요하면 `Buff.WarningSound.Debug 1`을 입력한다.
확인 후에는 `Buff.WarningSound.Debug 0`으로 끈다.
